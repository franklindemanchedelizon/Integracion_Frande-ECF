# Registro de cambios

Cambios de esta guía y de los SDK de Frande ECF. Los cambios de la API se anuncian en la [referencia de la guía](guia/referencia.md).

## 0.1.2 · 2026-11-19
- El SDK de TypeScript ya se instala con `npm install @frandeone/ecf`.
- Cada versión de los SDK se publica con procedencia verificable (npm provenance).

## 0.1.1 · 2026-11-19
- Diagramas de arquitectura, emisión, estados y webhooks legibles en modo claro y oscuro.
- `composer require frandeone/ecf-sdk` instala solo el SDK de PHP, sin la guía ni los ejemplos.

## 0.1.0 · 2026-11-19
- Primera versión: guía completa para integradores, contrato OpenAPI `/v1`, contingencia, ejemplos, colección Bruno y SDK para TypeScript y PHP.
